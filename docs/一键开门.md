# 一键开门（贝壳找房辅助）

桌面点「一键开门」就会立刻打开贝壳找房，并自动点「我的 → 租约 → 智能门锁 → 蓝牙开门」。开锁成功后回到桌面并提示「开门成功」。开锁仍由官方贝壳完成，本应用不直连门锁蓝牙。

当前版本 **1.4.5**。桌面图标为深色底、薄荷绿开锁图案。许可证为 MIT，全文见仓库根目录 `LICENSE`。

开门成功后会退出贝壳回到桌面，正中弹出和贝壳「开门中」同款的黑底条，写「开门成功」。OPPO 需允许「后台弹出界面」，否则这条提示可能被拦住。

门锁页中间的「蓝牙开门」是网页圆钮，按文字经常点不中。本版本会认出门锁页后，直接点屏幕中上部圆钮位置，直到出现「开门中...」，结束后回到桌面并提示 **开门成功**。

## 环境要求

- JDK 17
- Android SDK：`minSdk` 26，`compileSdk` / `targetSdk` 34
- 使用仓库自带 Gradle Wrapper（8.9），无需单独安装 Gradle
- 首次构建需能访问 Gradle 官方发行地址以下载发行包
- 真机已安装并登录贝壳找房，且租约里能手动蓝牙开门

## 编译打包

在仓库根目录执行：

```bat
gradlew.bat assembleDebug
```

产物（相对仓库根目录）：

```
app/build/outputs/apk/debug/app-debug.apk
```

说明：

- APK 不提交到 git，每次在本机编译即可。
- 用生成的 debug 包安装；覆盖安装即可升级。
- OPPO 可能拦截未知来源安装：设置 → 安全和隐私 → 允许此来源安装。
- **若手机正在乱点，先到系统设置关掉「一键开门辅助」。** 装完后关掉再打开一次该开关。

## 第一次使用（OPPO / ColorOS 必做）

1. 安装 `app/build/outputs/apk/debug/app-debug.apk` 并打开本应用。若无障碍未开，会进入引导页。
2. 点「打开无障碍设置」，找到 **一键开门辅助**，打开开关。
3. 设置 → 应用 → 一键开门 → 允许 **后台弹出界面**（成功后才能在桌面弹出「开门成功」）。
4. 设置顶部搜索「自启动」→ 允许自启动、关联启动、后台活动。
5. 设置顶部搜索「耗电」→ 关闭后台冻结 / 自动优化。
6. 确认已安装并登录贝壳找房，且租约里能手动蓝牙开门。
7. 回到桌面，再点一次「一键开门」，手机靠近门锁。

## 日常

- 点桌面图标 = 开门；成功后退出贝壳回到桌面，弹出「开门成功」。
- 失败时留在贝壳页面，并弹出失败原因。
- 长按图标 → **设置**：改按钮文字（必须和贝壳页面上的字完全一致；App 改版后改这里即可，不用重装）。
- 从最近任务划回 **不会** 再开一次门。
- 若手机正在乱点：立刻到系统设置关闭「一键开门辅助」，不要反复点图标。

## 做不到的事

- 不绕过贝壳登录和租约。
- 不能 100% 感知锁有没有真正转开，只能读贝壳界面文字。
- 贝壳弹出更新/隐私/定位窗时，请先手动关掉再点本图标。
- 本应用只辅助点击官方贝壳界面，不直连门锁、不复制贝壳蓝牙协议。

## 卸载

卸载后到系统无障碍里确认「一键开门辅助」已消失即可。
