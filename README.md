# 一键开门

独立 Android 应用。点桌面图标即可辅助打开「贝壳找房」并点击蓝牙开门；成功后回到桌面提示「开门成功」。

开锁仍由官方贝壳完成，本应用不直连门锁蓝牙。

当前版本 **1.5.0**。许可证：[MIT](LICENSE)。

详细使用说明见 [`docs/一键开门.md`](docs/一键开门.md)。

## 它做什么

- 启动贝壳找房（`com.lianjia.beike`）
- 通过系统无障碍依次点击：我的 → 租约 → 智能门锁 → 蓝牙开门
- 成功：退出贝壳、回到桌面，正中弹出「开门成功」
- 失败：留在贝壳页面，并提示失败原因

## 它不做什么

- 不绕过贝壳登录和租约
- 不直连门锁蓝牙、不抓包仿造开锁指令
- 不能 100% 判断锁是否真的转开，只能读贝壳界面上的文字

## 环境要求

- JDK 17
- Android SDK（`compileSdk` / `targetSdk` 34，`minSdk` 26）
- 使用仓库自带的 Gradle Wrapper（Gradle 8.9），无需预先安装 Gradle
- 首次构建会从 Gradle 官方地址下载发行包，需要能访问外网
- 真机需已安装并登录「贝壳找房」，且租约里能手动蓝牙开门

## 编译打包

在仓库根目录执行：

```bat
gradlew.bat assembleDebug
```

Debug 安装包路径（相对仓库根目录）：

```
app/build/outputs/apk/debug/app-debug.apk
```

APK 不纳入版本库。覆盖安装即可升级。

**若手机正在乱点，先到系统设置关掉「一键开门辅助」。** 装完后把该开关关掉再打开一次。

OPPO 可能拦截未知来源安装：设置 → 安全和隐私 → 允许此来源安装。

## 使用摘要

1. 安装本应用并打开。若无障碍未开，会进入引导页。
2. 开启 **一键开门辅助**。
3. OPPO / ColorOS：允许「后台弹出界面」、自启动；耗电管理里关闭后台冻结。
4. 回到桌面，点「一键开门」，手机靠近门锁。
5. 长按图标 → **设置**：可改贝壳页面上的按钮文字，也可切换桌面图标（默认翠绿锁；另有深色锁、白底绿锁、细线锁、薄荷锁）。OPPO 若图标没马上变，回桌面等几秒，或从应用列表再拖一次。
6. 从最近任务划回 **不会** 再开一次门。

完整步骤、限制与卸载说明见 [`docs/一键开门.md`](docs/一键开门.md)。
