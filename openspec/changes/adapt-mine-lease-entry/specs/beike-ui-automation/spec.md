## ADDED Requirements

### Requirement: 新版我的页点击租约入口
当界面是贝壳「我的」页（含横向图标区「专属服务」「租约」「我的委托」等）时，系统 MUST 点击该页中的「租约」入口以进入租约流程，MUST NOT 因为已经点击过底栏「我的」而停止。系统 MUST NOT 把底栏「AI」或「消息」当成「我的」。系统 MUST NOT 在未认出「我的」页时按屏幕百分比乱点。

#### Scenario: 我的页可见租约图标
- **WHEN** 当前窗口可见「专属服务」与「我的委托」，或可见「购房计划书」与「浏览记录」，且尚未进入租约枢纽或智能门锁页
- **THEN** 系统 MUST 尝试点击「租约」（节点须在底栏上方）

#### Scenario: 无障碍暂时读不到租约文字
- **WHEN** 已认出上述「我的」页，但无障碍树里没有可点的「租约」文字节点
- **THEN** 系统 MUST 仅在该页按横向图标第二格的大约位置补点一次，MUST NOT 在首页或其它页使用该坐标

#### Scenario: 五格底栏仍点我的
- **WHEN** 当前是贝壳首页，底栏为「首页 / 我家 / AI / 消息 / 我的」
- **THEN** 系统 MUST 点击底部「我的」一格，MUST NOT 按四格底栏的第 4 格坐标点击
