## Context

截图（2026-09-15）为贝壳「我的」Tab：底栏五项含中间「AI」；中部功能区下有横向滑动图标「专属服务 / 租约 / 我的委托 / 优惠券 / 卖房」。路径仍是官方「我的 → 租约 → 智能门锁 → 蓝牙开门」，不直连门锁。

## Goals

- 认出该「我的」页并点中「租约」，进入原有租约/门锁流程。
- 无障碍树暂时没有「租约」文字时，不要因为已经点过「我的」而停住。

## Non-goals

- 不改门锁页圆钮坐标。
- 不恢复按屏幕比例乱点底栏。
- 不处理贝壳弹窗（更新/隐私）。

## Decisions

1. 把「当前页下一步」抽成无 Android 依赖的判断，用截图可见文案做 JVM 单测。
2. 「我的」页：`(专属服务 且 我的委托) 或 (购房计划书 且 浏览记录)`，且不是租约底栏/租约枢纽/门锁页。
3. 点「租约」：文字节点底边不超过屏幕约 86%（仍低于底栏）；失败且已是「我的」页时，补点约 `(0.30, 0.60)`（可见五个图标里的第二格）。
4. `when` 分支在「我的」页与「有租约文案」时都走点租约，避免 `leftHome` 吃掉重试。
