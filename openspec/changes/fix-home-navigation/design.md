## Context

用户截图停在贝壳首页，门锁入口不在这一页。

## Goals / Non-Goals

**Goals:** 从首页点进「我的」→「租约」→「智能门锁」；每步等页面出现再继续。

**Non-Goals:** 不改圆钮点击与回桌面逻辑。

## Decisions

1. 首页特征：出现「地图找房」或同时有「二手房」「新房」。
2. 底部「我的」用屏幕下方精确文案点击，失败则点坐标约 (87%, 96%)。
3. 多次失败后改点「我家」(37%, 96%)，省心租入口可能在这里。
4. 只有当前界面已有「租约」/「智能门锁」才点对应项。

## Risks / Trade-offs

- [底部栏高度因全面屏略有差异] → 文案点击优先，坐标兜底。
