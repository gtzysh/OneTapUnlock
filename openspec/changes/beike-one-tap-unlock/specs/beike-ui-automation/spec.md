## ADDED Requirements

### Requirement: 仅操作贝壳找房
无障碍服务 MUST 将可读取与点击的目标限制为包名 `com.lianjia.beike`。

#### Scenario: 包名白名单
- **WHEN** 无障碍服务接收窗口事件
- **THEN** 服务 MUST NOT 读取或点击非贝壳找房应用的界面内容来完成开门

### Requirement: 按官方路径点击开门
开门流程 MUST 依次尝试点击可配置文案，默认顺序为「我的」「租约」「智能门锁」「蓝牙开门」。

#### Scenario: 完整点击序列
- **WHEN** 开门流程已启动且贝壳界面出现对应文字节点
- **THEN** 服务 MUST 按顺序点击上述步骤，并在点击「蓝牙开门」（或用户配置的最后一步文案）后视为流程完成

#### Scenario: 步骤超时
- **WHEN** 某一步在超时时间内找不到可点击节点
- **THEN** 系统 MUST 停止后续点击并向用户展示失败原因

### Requirement: 点击文案可配置
系统 MUST 允许用户修改各步骤匹配文案，以便贝壳改版后无需重编译。

#### Scenario: 修改最后一步文案
- **WHEN** 用户在设置中将最后一步改为「立即开锁」并再次点图标开门
- **THEN** 流程 MUST 使用新文案匹配节点
