## Context

已有无障碍自动点击贝壳开门。用户要求：开门后返回结果信息，并美化 UI。

## Goals / Non-Goals

**Goals:** 点击开门按钮后识别贝壳成功/失败文案（或超时未确认），拉回本应用展示结果页；统一深色卡片视觉。

**Non-Goals:** 不直连 BLE；不保证 100% 读到锁端物理状态。

## Decisions

1. 点完最后一步后进入约 2.8 秒确认窗，扫描贝壳可见文字中的成功/失败关键词。
2. 用 MainActivity extras 展示结果，避免再点一次图标。
3. 无障碍服务 `startActivity` 拉回本应用，并短震 + 保留 Toast 作兜底。
4. UI：墨绿渐变 + 圆角卡片 + 状态图标，不引入新依赖。

## Risks / Trade-offs

- [贝壳文案不含「开锁成功」] → 展示「已发出开门指令」，提示看门锁。
- [ColorOS 拦截后台弹出] → 引导页强调该权限；Toast 仍能看到。
