## Context

租约页底栏：租房 / 地图找房 / 关注 / 租约 / 房东。智能门锁是上方右侧大卡片。

## Goals / Non-Goals

**Goals:** 租约页点「智能门锁」卡片；误入房东则点回租约。

**Non-Goals:** 不改门锁页圆钮点击。

## Decisions

1. `isHome` 必须同时有「二手房」「新房」「首页」，且没有「智能门锁」「切换租约」。
2. 有「智能门锁」且非门锁页时，用上半屏节点点击，Y 不超过屏幕 62%。
3. 出现「一键出租」或「我是房东」且无智能门锁时，点底栏「租约」。
4. `tapBottomTabSlot` 仅在确认是主站首页时使用。
