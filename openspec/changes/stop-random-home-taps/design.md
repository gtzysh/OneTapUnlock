## Context

用户反馈 1.4.0 仍停在贝壳首页，并且反复点击导致系统乱跳。

## Goals / Non-Goals

**Goals:** 停止乱点；只点贝壳底栏「我的」。

**Non-Goals:** 不改门锁页圆钮坐标逻辑。

## Decisions

1. 删掉 `tapPercent(0.875, 0.93/0.96)` 和点「我家」的坐标兜底。
2. 「我的」必须落在屏幕底部约 18% 内，且宽高像一格 Tab，禁止对整条底栏父节点执行点击。
3. 节点找不到时，最多 3 次按 `WindowMetrics` 减去导航栏 inset 后点第 4 格中心；之后只等节点，不再发手势。
4. 导航阶段若当前窗口包名不是 `com.lianjia.beike` 则不点。

## Risks / Trade-offs

- [底栏不暴露「我的」文字时只能靠 3 次格子点击] → 失败则 Toast 超时，不再乱点。
